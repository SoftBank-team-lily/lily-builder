# Lily 프론트엔드 디자인

히어로 제목은 “GitHub 레포 URL 하나로 빌드부터 배포, 트래픽 전환, 모니터링까지 자동으로 처리하는 배포 플랫폼”이다. 그 아래에 빌드·접속 주소·두 단계 설정을 풀어 쓰는 문장은 두지 않는다. 화면의 주인공은 배포 시작, 두 단계 설정, 진행 단계, 배포 후 대시보드다.

## 참고와 차별

소프트뱅크 웹에서 가져오는 것은 구조와 가독성뿐이다.

- 본문 글자는 흔히 보는 14~16px보다 크게 잡는다. 기본 18px, 제목은 한 단계 더 크게.
- 바탕은 `#FFFFFF`, 본문 글자는 `#333333`이다. 순흑은 쓰지 않는다.
- 경계와 보조 요소는 실버 `#C1C1C2`다.
- 첫 화면은 큰 배너 하나와, 그 아래 정보를 칸으로 나눈 그리드다.

가져오지 않는 것:

- 소프트뱅크 로고, 채용 사진 콜라주, 공유 버튼, 일본어, 채용 태그
- 사람 사진으로 채운 히어로
- 보라색 그라데이션, 큰 둥근 모서리, 진한 그림자

Lily만의 차이:

- 행동 버튼과 현재 단계 표시만 `#9B1B30`을 쓴다. 나머지 면은 흰색과 실버다.
- 모서리는 직각(`border-radius: 0`)이다.
- 글자는 Pretendard다. 일본어 문구를 넣지 않는다.
- 배너 문구는 배포 제품의 문장이다. 캠페인 슬로건을 흉내 내지 않는다.

## 토큰

| 이름 | 값 | 쓰임 |
| --- | --- | --- |
| 바탕 | `#FFFFFF` | 페이지, 칸 |
| 글자 | `#333333` | 본문, 제목 |
| 보조 글자 | `#5C5C5C` | 설명. 본문보다 작아도 18px 근처를 유지 |
| 실버 | `#C1C1C2` | 선, 표 머리, 비활성 칸 |
| 포인트 | `#9B1B30` | 주요 버튼, 현재 탭, 진행 중 단계 |
| 버튼 글자 | `#FFFFFF` | 포인트 버튼 위 |
| 성공 | `#166534` | 완료 상태. 색만으로 의미를 전하지 않고 글자를 함께 쓴다 |
| 실패 | `#991B1B` | 실패 상태. 글자를 함께 쓴다 |

간격은 4, 8, 12, 16, 24, 32, 48, 64px만 쓴다.

## 글자

```css
font-family: "Pretendard Variable", Pretendard, system-ui, sans-serif;
```

정적 페이지는 Pretendard Variable 스타일시트를 링크한다. 불러오지 못하면 system-ui로 떨어진다.

| 역할 | 크기 | 굵기 |
| --- | --- | --- |
| 배너 제목 | 40px, 좁은 화면 32px | 700 |
| 화면 제목 | 32px | 700 |
| 칸 제목 | 20px | 700 |
| 본문, 입력, 버튼, 표 | 18px | 400, 버튼은 700 |
| 보조 숫자, 로그 | 16px | 400 |

줄간격은 1.6이다. 한 화면에 h1은 하나다.

## 레이아웃

1. 상단 바: 왼쪽 `Lily`와 `배포 플랫폼`, 오른쪽 메뉴(배포, 실행 중, 이력). 높이 72px, 아래 실버 선.
2. 첫 화면 배너: 큰 제목, 한 문단, `배포하기` 버튼 하나. 사진 없음.
3. 배너 아래 3칸 그리드: 소스, 실행, 진행. 각 칸은 실버 테두리와 큰 번호.
4. 설정은 배너에 두지 않는다. `배포하기` 다음 두 단계(소스, 실행)로 연다.
5. 진행 화면은 네 단계를 세로로 쌓고, 현재 단계만 포인트 색 테두리와 로딩으로 표시한다.
6. 성공 후 대시보드는 같은 그리드로 지표를 놓고, 샘플 값에는 `샘플`을 글자로 붙인다.

좁은 화면(720px 이하)에서는 그리드를 한 열로 접는다. 글자 크기는 줄이지 않는다.

## 금지

- 일본어, 소프트뱅크 고유 문구, 타사 로고
- 첫 화면에 GitHub 주소 입력란을 펼쳐 두는 것
- 지표 샘플을 실제 수집 값처럼 보이게 하는 것
